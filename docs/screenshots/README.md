# Application Screenshots Guide

This directory holds screenshots demonstrating the core user interfaces of SwasthyaVani for documentation, user guides, and repository presentations.

## Recommended Screenshots to Capture

When preparing images for this repository, capture the following screens at standard desktop resolution (1280x800) or mobile device preview (360x780):

1. `01-ask-protocols.png`:
   - View: `Ask Protocols` screen
   - Recommended State: Clinical query entered (e.g. *"severe headache and blurred vision during pregnancy"*), displaying the Layer 1 Emergency Danger alert with 108 ambulance guidance and section citation (`ESC-1.1`).
2. `02-beneficiaries-register.png`:
   - View: `Beneficiaries` screen
   - Recommended State: Filter applied (e.g. village filter or `High Risk` category) showing filtered records with the *Add new beneficiary* button visible.
3. `03-beneficiary-modal.png`:
   - View: `Beneficiary Details` modal
   - Recommended State: Modal open for a high-risk pregnancy record, displaying vitals, care history, assigned ASHA, and trilingual audio buttons.
4. `04-visit-planner.png`:
   - View: `Daily Visit Planner` screen
   - Recommended State: Active date selected, showing priority groups (`Urgent`, `Due today`, `Overdue`, `Upcoming`) and route navigation.
5. `05-dashboard.png`:
   - View: `Monthly Dashboard` screen
   - Recommended State: Showing the 30-day activity trend SVG bar chart, village progress breakdown, and high-contrast mode toggle.
6. `06-offline-mode.png`:
   - View: Header and network offline status
   - Recommended State: Browser offline with green checkmark indicating all records and protocols cached locally.
